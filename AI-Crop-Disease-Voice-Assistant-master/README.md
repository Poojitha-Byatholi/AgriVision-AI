# 🌱 AgriVision AI – Intelligent Agricultural Advisory System

AgriVision AI is an AI-powered agricultural advisory system designed to support farmers by providing crop disease detection, weather forecasting, chatbot assistance, and voice-based interaction through a single platform.

The system combines deep learning and interactive technologies to help farmers identify crop diseases, access weather information, and receive agricultural guidance in an accessible way.

## 🚀 Features

- **Crop Disease Detection:** Detects crop diseases from uploaded leaf images using a deep learning model based on MobileNetV2.
- **Weather Forecasting:** Provides weather information to help farmers make informed agricultural decisions.
- **AI Chatbot:** Offers chatbot-based assistance for agricultural queries.
- **Voice Assistant:** Enables voice-based interaction to make the platform easier to use.
- **Interactive Interface:** Provides a user-friendly interface developed using Streamlit.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Deep Learning:** TensorFlow / Keras
- **Deep Learning Model:** MobileNetV2
- **Frontend / Application Framework:** Streamlit
- **Natural Language Processing:** Chatbot functionality
- **APIs:** Weather API
- **Other Libraries:** NumPy, Pandas, OpenCV, Pillow

## ⚙️ System Workflow

1. The user uploads a crop leaf image.
2. The trained MobileNetV2 model processes the image.
3. The system predicts the possible crop disease.
4. Users can access weather information.
5. The chatbot and voice assistant provide additional agricultural assistance.
